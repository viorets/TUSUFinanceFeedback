# แนวปฏิบัติกองกิจ / อมธ.

> เป็น**แนวปฏิบัติ** ของกองกิจการนักศึกษาและฝ่ายแผนงานและงบประมาณ อมธ. จากสไลด์ "ข้อมูลภายใน" ไม่ใช่ข้อความในระเบียบหรือประกาศ หากขัดกับระเบียบ ให้ถือระเบียบเป็นหลัก

<a id="kk-approval"></a>
## การขออนุมัติโครงการ

ส่งเอกสารที่กองกิจการนักศึกษา และดำเนินเอกสารขออนุมัติโครงการที่ใช้งบประมาณ ได้แก่

1. แบบขออนุมัติโครงการที่ใช้งบประมาณมหาวิทยาลัย (FM-STA-02)
2. เอกสารหนังสือโครงการ
3. ใบแจ้งผลการพิจารณาจากสภานักศึกษา

กองกิจตรวจสอบรายละเอียดรายการงบประมาณและดำเนินเรื่องเงินยืม แล้วส่งดำเนินเรื่องกับกองคลัง

<a id="kk-loan"></a>
## เงินยืม

- กรณีต้องการยืมเงินก่อนจัดโครงการ โปรดติดต่อกองกิจการนักศึกษาล่วงหน้า **2 เดือน**
- วันที่ในบิลต้องอยู่ในกรอบเวลาของโครงการ และต้องไม่เกิดขึ้นก่อนได้รับเงินยืม

<a id="kk-sponsor"></a>
## เงินจากผู้สนับสนุน

- ผู้สนับสนุน**ต้องการ**ใบลดหย่อนภาษี: โอนเข้าบัญชีมหาวิทยาลัย แล้วยืมเงินผ่านกองกิจ หรือกองคลังโอนตรงให้ผู้รับจ้าง หลักฐานคือ ใบเสร็จรับเงิน และใบกำกับภาษี
- ผู้สนับสนุน**ไม่ต้องการ**ใบลดหย่อนภาษี: รับเข้าบัญชีองค์กร หรือบัญชีอาจารย์ที่ปรึกษา
- ทุกกรณีต้องแจกแจงรายรับจากผู้สนับสนุนในรายงานโครงการ (ระเบียบงบประมาณ 2569 ข้อ 60)

<a id="kk-quotation"></a>
## ใบเสนอราคา

**ออกในนาม** องค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์ **ที่อยู่** 99 หมู่ 18 ถ.พหลโยธิน ต.คลองหนึ่ง อ.คลองหลวง จ.ปทุมธานี 12120 **เลขประจำตัวผู้เสียภาษี** 099-4-00016086-1

องค์ประกอบของใบเสนอราคา

1. ผู้ให้บริการ: ชื่อบุคคล/ร้าน/บริษัท ที่อยู่ เลขประจำตัวผู้เสียภาษี
2. ผู้รับบริการ: ออกในนามองค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์ พร้อมที่อยู่และเลขประจำตัวผู้เสียภาษี
3. รายการสินค้าโดยละเอียด: รายการ จำนวน ราคาต่อหน่วย ราคารวม; มูลค่ารวมสุทธิต้อง**รวมภาษีมูลค่าเพิ่ม (VAT)**; ขอใบเสนอราคาตั้งแต่ 2 ใบ รายการสินค้าและหน่วยต้อง**เหมือนกัน**
4. เงื่อนไขอื่น เช่น อายุใบเสนอราคา
5. เงื่อนไขการชำระเงิน; มูลค่าสูงให้สอบถามเครดิตเทอมจากผู้ให้บริการ

รายการที่ต้องแนบใบเสนอราคาตามระเบียบงบประมาณ 2569: ที่พักเชิงธุรกิจ (ข้อ 34), จ้างเหมารถรับ-ส่ง ≥ 2 ราย (ข้อ 36 (1)), จ้างเหมาจัดงาน เวที แสง สี เสียง ≥ 2 ราย (ข้อ 37), เช่าสถานที่ (ข้อ 38), เช่าวัสดุอุปกรณ์ ≥ 3,000 บาท/รายการ (ข้อ 40 (2)), วัสดุ ≥ 2,000 บาท/โครงการ (ข้อ 41 (2)), ครุภัณฑ์ ≥ 2,000 บาท/โครงการ (ข้อ 42 (2)), ศิลปิน/ผู้ตัดสิน (ข้อ 44), ค่าใช้จ่ายอื่น (ข้อ 50: ใบเสนอราคา**หรือ**แจกแจงพร้อมหลักฐาน)

<a id="kk-receipt"></a>
## ใบสำคัญรับเงิน (รังสิต)

1. สำเนาบัตรประชาชน**ประธานชุมนุม**เท่านั้น ชื่อต้องตรงกับใบแต่งตั้งคณะกรรมการ
2. Passport เซ็นที่อยู่ตามสำเนา
3. เอกสารแต่งตั้งคณะกรรมการชุมนุม
4. ช่องจำนวนเงินลงท้ายถ้วย
5. ประธานชุมนุมเซ็น**สีแดง**

<a id="kk-evidence"></a>
## หลักฐานการจ่ายเงิน

หลักฐานต้องเป็น**ต้นฉบับ** ซึ่งเป็นเอกสารกระดาษที่พิมพ์หรือเขียนด้วยหมึก รายการหลักฐานแยกตามประเภทค่าใช้จ่ายอยู่ในโหมดสรุป หัวข้อ "หลักฐานแต่ละรายการ"

<a id="kk-excel"></a>
## ไฟล์ Excel แบบรายการงบประมาณ

1. ห้ามแก้ไขข้อมูลในหน้า summary ยกเว้นชื่อชุมนุม ใช้สำหรับดูยอดรวมงบประมาณของแต่ละชุมนุมเท่านั้น
2. ห้ามแก้ไขชื่อหน้าชีท เช่น โครงการ1 → โครงการกิจกรรมแสนสนุก
3. ห้ามลบหน้าชีท เช่น ยื่น 2 โครงการ แก้ไขแค่หน้า โครงการ1 และ โครงการ2 ส่วนโครงการ3 → โครงการ10 ไม่ต้องลบ
4. ตัวเลขต้องเท่ากันทั้งช่องยืมเงินและไม่ยืมเงิน และแจกแจงรายละเอียดการใช้จ่ายด้วย
